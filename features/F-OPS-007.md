# F-OPS-007 Known version

## Statement

Everyone can see which version of Musicus runs, and every document of a release names the version it describes.

## Rationale

An administrator needs the version to choose the right user guide, to read release notes and to know which older releases a downgrade can return to (R-OPS-014); users need it when they report a problem.
