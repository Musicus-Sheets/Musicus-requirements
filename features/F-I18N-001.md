# F-I18N-001 Musicus in the user's language

## Statement

Musicus shall show its user interface, dates, numbers, error messages, part names and sort order in the language of the user's browser (English if that language is not available), while all data is stored and shown exactly as entered.

## Rationale

Ensembles and their members do not all speak English; a library that members find hard to use is not used. Translating the data itself (titles, instruments, tags) would change what the librarian entered, so only the words of the program are translated.

## Notes

English is the source language and the fallback. German follows first. The server sends no text for users (R-I18N-004); the client composes every sentence.
