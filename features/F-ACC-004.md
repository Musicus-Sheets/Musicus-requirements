# F-ACC-004 Management where the music is

## Statement

Librarians and admins maintain the library, the programmes and the instrument list directly in the views every user works with, and members see the same views without the management options.

## Rationale

A separate management area duplicates the library and programme lists and forces librarians to search for the same piece twice. Working in place ("open the piece, click Edit") is easier to learn and to explain, and one set of views keeps the user guide short.
