# R-ACL-005 Grants per voice

## Statement

The system shall allow granting an instrument to a group for selected voices only (e.g. Trumpet voice 1).

## Acceptance criteria

- A group granted 'Trumpet, voice 1' reads '1st Trumpet' but not '2nd Trumpet'.
