# R-ACC-012 Send invite links by e-mail

## Statement

When an operator configured an SMTP server, the system shall offer to send invite and reset links to the user's e-mail address.

## Acceptance criteria

- With SMTP configured, creating a user with an e-mail address sends the invite link to it.

## Notes

SMTP stays optional: without it, librarians hand out links through any messenger (see R-ACC-001).
