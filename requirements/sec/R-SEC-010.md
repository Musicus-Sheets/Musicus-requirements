# R-SEC-010 Download audit log

## Statement

The system shall record which user downloaded which file version and when, and let admins view this log.

## Acceptance criteria

- After a member opens a part, the admin sees an entry with member, part, version and time.

## Notes

Deterrent against unauthorised distribution of licensed music; must respect privacy rules for personal data (retention period).
