# R-ANN-020 Readable export of annotations

## Statement

The system shall let members (and developers for debugging) export an annotation set as JSON.

## Acceptance criteria

- The export of a set lists every object of every page with its type, position and colour.

## Notes

The stored format is binary (postcard); a JSON export makes it inspectable.
