# R-I18N-003 English fallback per message

## Statement

When a message is missing in the chosen language, the web client shall show the English message in its place; it shall never show a message key or an empty text.

## Rationale

Translations grow over time (community translation); an incomplete language must stay usable.

## Acceptance criteria

- A message present only in the English catalogue is shown in English while the rest of the page is in the chosen language.
- Building the client fails when code uses a message the English catalogue does not contain, or passes other arguments than the English message uses.
