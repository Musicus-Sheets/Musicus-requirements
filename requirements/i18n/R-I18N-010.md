# R-I18N-010 No user-visible text outside the message catalogue

## Statement

Every text the web client shows (text, placeholders, titles, ARIA labels, confirmation and prompt dialogs) shall come from the message catalogue; only user data and a short allowlist of symbols ("×", "↑", the brand name) may appear literally.

## Rationale

A literal in the code cannot be translated and is found only by a native speaker by chance.

## Acceptance criteria

- A lint over the client sources fails on a string literal in a text position of `rsx!` or in `confirm`/`prompt` that is not allowlisted.
- With the pseudo-locale every checked control text of the end-to-end run is marked as translated.
