# R-I18N-006 Data as entered; derived names composed in the browser

## Statement

The system shall store and show titles, composers, tags, notes, instrument names, families, group names, voices, custom part names, programme texts and annotation-set names exactly as entered and shall never translate them. The server shall send the components of a part name (custom name, instruments with their names, key code, voices) instead of a composed name; the web client shall compose the derived part name, the key names and the name of an unnamed annotation set in the user interface language.

## Rationale

The ensemble's data belongs to the ensemble: a German band's "Klarinette" stays "Klarinette" for an English reader. Only the words Musicus adds ("in", key names, "My annotations") follow the reader's language.

## Acceptance criteria

- The part API (`Part`) contains no composed name; the reader, library, editors and import review show the same name as before in English ("Trumpet in B♭ 1").
- A set created by the reader without a name is stored without a name (NULL) and shown as "My annotations" in English.
- Existing sets named exactly "My annotations" are shown in the user interface language after the upgrade.
