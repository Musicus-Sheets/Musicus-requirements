# R-I18N-005 Dates, times and numbers in the UI language

## Statement

The web client shall format dates, times, file sizes and other numbers by the conventions of the user interface language (through the browser's `Intl` API), and shall choose plural forms by that language's rules.

## Rationale

"24.12.2026" and "12/24/2026" mean the same day only to readers of the respective convention; decimal separators differ too.

## Acceptance criteria

- With English the programme date 2026-12-24 is shown as the browser's English date form; the file size 1 500 000 bytes as "1.5 MB".
- Counts use the plural rules of the language ("1 page", "2 pages" in English).
