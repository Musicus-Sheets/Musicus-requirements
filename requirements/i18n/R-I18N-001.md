# R-I18N-001 User interface in the browser's language

## Statement

The web client shall show its user interface in the first language of the browser's preferred languages (`navigator.languages`) that Musicus ships, compared by language subtag ("de-AT" selects German), and shall set `lang` of the HTML document to that language. Musicus shall offer no language setting and shall store nothing about the language, neither on the server nor on the device.

## Rationale

The browser already knows which languages its user reads; a setting per user would need storage, an extra control on the login page and would differ between the devices of one person. Nothing may be stored on the device (R-SEC-001).

## Acceptance criteria

- With `navigator.languages` = ["fr-FR", "de-CH", "en"] and German shipped but French not, the interface is German and `document.documentElement.lang` is "de".
- The login and invite pages follow the same rule as the pages after login.
- No database column, endpoint, cookie or browser storage holds a language.
