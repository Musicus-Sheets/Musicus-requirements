# R-I18N-008 Lists sorted by the rules of the UI language

## Statement

The web client shall sort every displayed list of names (library, parts of a piece, instruments, groups, users, programme pieces, picker entries, import review) with the collation of the user interface language, ignoring case and comparing numbers by value.

## Rationale

Code-point order puts "Ö" after "Z" and "Trumpet 10" before "Trumpet 2".

## Acceptance criteria

- "Ölberg" sorts between "Oboe" and "Posaune" in German and English.
- "Trumpet 2" sorts before "Trumpet 10".
