# R-I18N-009 User guide per shipped language

## Statement

The user guide shall exist in every shipped user interface language, and the button and field names it quotes shall equal the user interface texts of that language.

## Rationale

A guide in another language than the interface makes buttons hard to find.

## Acceptance criteria

- The German guide quotes the German button names; a check fails when a quoted name is not a message of that language.
