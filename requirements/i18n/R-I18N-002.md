# R-I18N-002 English when no browser language is shipped

## Statement

When none of the browser's preferred languages is shipped, the web client shall show its user interface in English.

## Rationale

English is the source language of all messages and always complete.

## Acceptance criteria

- With `navigator.languages` = ["fr-FR"] the interface is English and `lang` is "en".
