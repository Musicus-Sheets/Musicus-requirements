# R-READ-007 Half-page turns

## Statement

The web client shall offer a mode in which a page turn first replaces only the upper half of the screen with the upper half of the next page.

## Acceptance criteria

- In half-page mode the musician sees the end of page 1 and the start of page 2 at the same time.

## Notes

Kept as a page-view option (decision November 2026). The system view (F-READ-003, R-READ-013) already shows the end of one page and the start of the next together and is the preferred way on small tablets; half-page turns would still help on large screens in portrait, where whole pages are readable but the turn comes too early.
